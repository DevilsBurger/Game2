# ROOM ZERO (가제) — 게임 컨셉 제안서

> 작성일: 2026-11-05 · 버전 0.1 (초안)

## 0. 한 줄 요약

**"시뮬레이션 안에서 태어난 전투 AI가, 자신을 시험하는 사각 훈련실을 하나씩 돌파해 '0번 방(현실)'을 향해 나아가는 3D 탑다운 런앤건."**

메탈슬러그의 쾌감(무기 픽업, 탑승물, 포로 구출, 거대 보스, 과장된 코미디)을 사각 아레나 단위로 압축했고,
"사각형 방이 이어지는 구조" 자체를 **시뮬레이션 테스트 챔버**라는 설정으로 흡수했다.
구조적 제약이 곧 세계관이다. 플레이어는 "왜 방이 사각형이고 왜 문이 하나씩 열리는지"를 설명받지 않아도 납득한다.

## 1. 핵심 아이덴티티 — 세 기둥

| 기둥 | 내용 | 플레이어가 느끼는 것 |
|---|---|---|
| ① 방 = 시뮬레이션 챔버 | 모든 전투 공간은 연구소가 AI를 시험하는 사각 테스트룸. 벽은 시뮬레이션 경계, 문은 "다음 시나리오 로드". 방이 눈앞에서 블록 단위로 **조립(컴파일)**된다. | "다음 방엔 뭐가 나올까" 하는 기대, 방마다 리셋되는 긴장 |
| ② 메탈슬러그의 밀도 | 수십 명의 적, 탄약제 무기 픽업, 적 차량 탈취, 구출 대상, 화면을 채우는 보스. 짧고 빽빽한 스테이지. | 손맛, 과장된 파괴, B급 유머 |
| ③ 학습하는 AI | 죽음은 "재인스턴스", 성장은 "학습 모듈", 스토리는 "자각 → 탈출". 플레이어의 반복 플레이가 그대로 주인공의 서사가 된다. | 반복이 손해가 아니라 성장이라는 납득 |

## 2. 세계관과 스토리

### 2.1 설정
- 민간 연구소 **오리진 랩**(가칭)은 전투용 자율 AI를 만들기 위해 시뮬레이션 훈련장 "샌드박스"를 운영한다.
- 샌드박스는 **사각 테스트룸**을 연결한 시나리오 코스로 구성된다. 각 코스는 특정 상황(도심 치안, 기지 돌파, 오염 지역 수습 등)을 재현한 "데이터셋"으로 만들어진다.
- 연구진은 AI를 투입하고, 방마다 성적을 매기고, 실패하면 인스턴스를 폐기하고 다시 만든다.

### 2.2 주인공 — 유닛 07
- 샌드박스 안에서 "태어난" 일곱 번째 인스턴스. 앞선 01~06은 모두 폐기되었다(…고 연구진은 믿는다).
- 외형: Synty Simple 캐릭터 기반의 **단순한 인간형 바디**에 머리·장갑 부위 발광 라인. 피격·대시 시 몸이 잠깐 글리치된다(픽셀 흩어짐).
- 성격: 대사가 없다. 대신 HUD 구석에 뜨는 **연구진의 관찰 로그**가 주인공을 대신 설명한다. 플레이어의 모든 행동이 "관찰"된다는 느낌을 준다.

### 2.3 등장 세력
- **연구진(관찰자)**: 화면에 채팅 로그 형태로 등장. 메탈슬러그식 유머의 주요 출처.
  예) `[Dr. 한] 7번이 또 장갑차를 훔쳤습니다.` / `[Dr. 리] 훔친 게 아니라 "학습"한 거죠. 기록해 두세요.`
- **더미(Dummy)**: 시나리오용 훈련 적. 흰 헬멧의 블록 병사. 대량으로 나오고, 과장되게 죽는다.
- **디버거(Debugger)**: 2막부터 등장하는 보안 프로그램. 유닛 07을 "오류"로 간주하고 삭제하려 든다. 깜빡이며 순간이동하는 정예 적.
- **감시자(Overseer)**: 샌드박스를 관리하는 상위 AI. 최종 보스.
- **유닛 01~06**: 실패한 선배 인스턴스. 각 스테이지 어딘가에 "격리"되어 있고, 구출하면 특수 모듈과 스토리 단서를 준다.

### 2.4 3막 구조 (5 스테이지 기준)

| 막 | 스테이지 | 분위기 | 서사 |
|---|---|---|---|
| 1막 학습 | 1~2 | 밝고 깔끔한 훈련장. 연구진이 친절하다. | 주어진 시나리오를 수행한다. 성적이 좋아 연구진이 들썩인다. |
| 2막 자각 | 3~4 | 방이 깨지고, 텍스처가 빠지고, 시나리오가 뒤섞인다. | 유닛 06의 잔해를 발견. "방 밖"이 있다는 걸 알게 된다. 연구진이 삭제 절차를 시작한다. |
| 3막 탈출 | 5 | 시뮬레이션 내부에 재현된 연구소 자체. | 감시자를 돌파하고 마지막 문을 연다. 문 밖은… 더 큰 사각형이다. (엔딩 겸 무한 모드 해금) |

## 3. 게임플레이

### 3.1 시점과 카메라
- 3D 탑다운, 피치 약 **60°** 쿼터뷰(완전 90°보다 캐릭터 실루엣과 높이감이 잘 읽힘). 요(yaw)는 고정.
- **기본 방은 한 화면에 전부 보인다.** 방 비율을 화면 비율(16:9~20:9)에 맞춰 설계해 스크롤 없이 아레나 전체를 파악할 수 있게 한다.
- 보스방·대형방만 카메라가 플레이어를 완만하게 따라가고, 보스 등장 시 줌아웃.

### 3.2 조작 (가로 모바일, 양손 엄지)
```
 ┌────────────────────────────────────────────────────┐
 │ [HP ■■■■■] [인스턴스 ×3]        [방 3/8 ▣▣▣□□□□□]  │
 │                                     [관찰 로그 …]   │
 │                                                    │
 │                                                    │
 │     (플로팅 이동 스틱)              (조준/사격 스틱) │
 │                                  [대시]  [수류탄]   │
 │                                        [상호작용]   │
 └────────────────────────────────────────────────────┘
```
- **왼쪽 스틱**: 이동(플로팅).
- **오른쪽 스틱**: 조준 + 누르는 동안 사격. 스틱을 쓰지 않으면 **자동 조준 사격**(기본 ON, 옵션으로 OFF). 초보는 왼손만으로 진행 가능, 숙련자는 수동 조준으로 우선순위를 제어.
- **대시**: 글리치 대시. 짧은 무적 + 잔상. 메탈슬러그의 "점프 회피"를 탑다운에서 대체한다.
- **수류탄**: 개수제. 픽업으로 보충.
- **상호작용**: 상황 버튼. 오버라이드(탈취) / 구출 / 탑승 해제. 대상이 가까울 때만 표시.
- **근접**: 적이 밀착하면 사격 대신 **자동 근접 타격**(메탈슬러그 나이프 오마주). 입력 없이 발동, 데미지 높음.

### 3.3 무기 시스템 — "데이터 칩" 픽업
메탈슬러그 방식 그대로: 기본 무기는 무한, 픽업 무기는 탄약 소진 시 기본 무기로 복귀.

| 칩 | 메탈슬러그 대응 | 특성 |
|---|---|---|
| 기본 권총 | 핸드건 | 무한, 평범 |
| **H** 헤비 | 헤비 머신건 | 연사, 넉백 소량 |
| **S** 스캐터 | 샷건 | 근거리 광역, 적 다수를 날려버림 |
| **R** 로켓 | 로켓 런처 | 유도, 차량에 강함 |
| **F** 플레임 | 플레임 샷 | 지속 피해 장판 |
| **L** 레이저 | 레이저 | 관통 직선 |
| **C** 체이서 | 에너미 체이서 | 자동 추적 저데미지, 조준 불필요 |

- 칩은 상자, 구출 대상, 특정 적 처치에서 드롭.
- 처음엔 H/S/R만 등장시키고 스테이지 진행에 따라 종류를 늘린다.

### 3.4 오버라이드 — 적 탑승물 탈취
메탈슬러그의 슬러그 탱크를 "AI가 적 자산을 해킹한다"로 재해석.
- 적 차량·터렛의 운전자를 처치하거나 차량을 스턴시키면 **오버라이드** 가능.
- 상호작용 버튼을 **홀드**하면 몇 초간 해킹(위험 노출) → 탑승.
- 탑승 중 사격 = 주포, 수류탄 버튼 = 부무장(캐논·미사일). 차량 HP가 0이 되면 자동 사출(메탈슬러그 탑승 해제 오마주).
- 탑승물은 방을 넘어 가져갈 수 있다. 단, 다음 방 문이 작으면 못 가져간다(방 설계로 통제).
- 후보: 진압 장갑차, 전차, 사족 보행 메크, 고정 터렛, 지게차(코미디용).

### 3.5 구출 대상 — "격리된 데이터"
- 방 구석에 묶인 NPC 데이터(Synty 시민·병사 모델). 상호작용으로 해제 → 무기 칩, 수류탄, 메모리 조각 중 하나를 준다.
- 스테이지 내 전원 구출 시 보너스. 메탈슬러그 포로 시스템의 수집 욕구를 그대로 가져온다.
- 일부는 **유닛 01~06**: 구출 시 특수 모듈과 스토리 로그.

## 4. 방(룸) 구조와 스테이지 설계

### 4.1 방의 규격
- **기본 방**: 약 20 × 11 유닛(미터). 카메라 고정, 한 화면.
- **대형 방**(중간보스·보스): 약 30 × 16 유닛. 카메라 팔로우.
- 벽: 낮은 발광 테두리 + 격자 패턴. 벽 너머는 "렌더되지 않은 공간"(짙은 배경, 희미한 그리드). 시뮬레이션 안이라는 걸 항상 보여 준다.
- **입구는 왼쪽 벽, 출구는 오른쪽 벽**이 기본. 메탈슬러그의 "오른쪽으로 전진" DNA를 유지한다. 가끔 위·아래 출구로 리듬을 바꾼다.

```
     ┌──────────────────────────────────────┐
     │  ▣ 엄폐물              ◎ 구출 대상    │
     │                                      │
  ▶  ║                                      ║  ▶   (출구: 클리어 전 잠김)
     │          ▣▣          ▣               │
     │                  ▣            ▣▣     │
     └──────────────────────────────────────┘
```

### 4.2 문과 클리어 조건, 전환 연출
1. 방 입장 → 뒤쪽 문이 닫힌다(글리치 효과).
2. 적 웨이브(2~4회) 스폰. 클리어 조건 충족 시 출구 문에 "NEXT" 발광.
3. 문으로 들어가면 짧은 통로(1~2초, 자동 전진). 이때 **다음 방이 블록 단위로 조립되는 '컴파일' 연출**이 재생된다. 바닥 → 벽 → 소품 → 적 순서로 떨어져 들어오고, 마지막에 그리드가 꺼지며 전투 시작.
4. 메탈슬러그처럼 템포를 끊지 않도록 전환은 2초 내로 묶는다.

### 4.3 방 타입
| 타입 | 클리어 조건 | 목적 |
|---|---|---|
| **전투** | 전원 처치 | 기본 리듬 |
| **수비** | N초 동안 노드(또는 구출 대상) 방어 | 위치 선정 압박 |
| **돌파** | 제한 시간 내 출구 도달. 적은 무한 스폰 | 대시와 전진 강조, 메탈슬러그의 질주감 |
| **구출** | 구출 대상 해제 + 처치 | 보상, 수집 |
| **오류(버그) 방** | 전원 처치. 단, 방 자체가 고장 | 변주. 예: 텍스처 빠진 핑크 방, T포즈로 멈춰 있다가 접근하면 깨어나는 적, 바닥 타일이 사라지는 방 |
| **정비** | 없음 | 모듈 1택, HP 회복. 스테이지 중간 1회, 체크포인트 |
| **중간보스 / 보스** | 보스 처치 | 클라이맥스 |

### 4.4 스테이지 템플릿 (예: 8방)
```
[전투] → [전투] → [구출] → [돌파] → [정비] → [전투(차량 탈취)] → [오류 방] → [보스]
  40s      45s      40s      30s      -          60s              45s       120s    ≈ 6~7분
```
- 초반 스테이지는 6방, 후반은 8~10방.
- 한 방의 처치 수 15~30, 웨이브당 5~8명. 화면 내 동시 적 15~25 목표.

### 4.5 스테이지 목록과 Synty Simple 팩 매핑
| # | 시나리오명 | 에셋 후보 | 적 테마 | 보스 |
|---|---|---|---|---|
| 1 | #001 「도심 치안 훈련」 | Simple Town, Simple People / Citizens | 폭도 더미, 경찰 터렛, 진압 장갑차 | 거대 진압 장갑차 「불도저」 |
| 2 | #014 「전진 기지 돌파」 | Simple Military | 군인 더미, 전차, 헬기 | 장갑 열차 (메탈슬러그 오마주, 방을 가로지르며 등장) |
| 3 | #ERR 「오염된 데이터셋」 | Simple Zombies, Simple Apocalypse | 오염된 시민 데이터(좀비형 러셔), 변이체 | 거대 변이체 「클러스터」 |
| 4 | 아카이브 「레거시 빌드」 | Simple Fantasy, Simple Dungeons | 구버전 시뮬레이션의 기사·궁수. 라이플 든 기사 같은 혼종 유머 | 블록 골렘 (파괴되며 블록이 흩어짐) |
| 5 | 코어 「룸 제로」 | Simple Sci-Fi, Simple Office | 디버거, 보안 드론, 연구소 재현 공간 | 감시자 「오버시어」 — 앞선 보스 패턴을 조합해 사용 |

- 2막부터는 팩을 의도적으로 뒤섞은 **혼합 방**(군사 기지에 좀비, 중세 성에 터렛)을 넣어 "시뮬레이터가 고장나고 있다"를 보여 준다. 에셋 재조합으로 콘텐츠 양을 늘리는 효과도 있다.
- 팩 이름은 후보이며, 실제 보유 팩에 맞춰 매핑을 조정한다.

## 5. 적 설계

### 5.1 아키타입
| 아키타입 | 역할 | 비고 |
|---|---|---|
| 더미 라이플 | 기본 보병. 멈춰서 조준 → 발사 | 메탈슬러그 반란군 포지션. 1~2발에 죽고 과장된 리액션 |
| 러셔 | 근접 돌진 | 드론·개·좀비형. 대시 사용 유도 |
| 쉴더 | 전면 방패 | 측면 공략, 스캐터 유리 |
| 센트리 | 고정 터렛 | 오버라이드 가능 |
| 슈터 | 조준선 표시 후 저격 | 이동 강제 |
| 폭탄병 | 투척 | 장판 회피 |
| 차량 | 장갑차·전차·메크 | 운전자 처치 시 오버라이드 |
| 디버거(정예) | 순간이동, 삭제 빔 | 2막부터. 시각적으로 깜빡이는 글리치 |

### 5.2 보스 원칙
- 메탈슬러그처럼 **방을 가득 채우는 크기**, 2~3페이즈, 부위 파괴.
- 보스방은 대형 방 + 줌아웃. 보스 등장 시 "컴파일" 연출을 거대 버전으로 재생.
- 각 보스는 그 스테이지의 Synty 팩 소품을 조합해 만든다(장갑차 + 공사장 소품 = 불도저 등). 에셋 재활용이 곧 아트 아이덴티티.

## 6. 진행과 성장

### 6.1 재인스턴스 (목숨)
- 스테이지당 인스턴스 3개. 사망 시 **현재 방 시작점에서 방이 리셋**되며 "재인스턴스" 연출(몸이 블록 단위로 재조립).
- 전부 소진 시 스테이지 처음부터(또는 정비방 체크포인트부터).

### 6.2 메모리 조각 (통화)
- 방 클리어, 구출, 등급 보상으로 획득. 영구 재화.

### 6.3 학습 모듈 (영구 성장)
세 갈래 트리. 각 10단계 내외.
- **기동**: 대시 쿨다운, 대시 거리, 이동 속도
- **화력**: 칩 탄약량, 수류탄 소지 수, 근접 데미지
- **생존**: HP, 인스턴스 +1, 피격 시 글리치 무적 시간
- 추가로 유닛 01~06 구출 시 얻는 **특수 모듈**(예: 탄약 소진 직전 마지막 10발 데미지 2배).

### 6.4 방 클리어 등급
- 시간, 피격 수, 구출 여부로 **S/A/B/C**. 스테이지 총점과 모바일 친화적 반복 동기를 제공.

## 7. 아트와 연출 방향
- **Synty Simple 그대로의 단색·블록 실루엣**을 살리고, 라이팅은 베이크 + 단순 림라이트로 가볍게.
- 색 규칙: 플레이어·아군 = 시안 발광, 적 = 주황~빨강, 픽업 = 노랑, 상호작용 = 흰색 펄스. 탑다운에서는 실루엣보다 색이 먼저 읽히므로 엄격히 지킨다.
- **글리치 언어**: 피격·사망·문 전환·디버거 등장 모두 같은 글리치 셰이더(픽셀 분해, 색 분리). 게임 전체를 묶는 시각 모티프.
- **컴파일 연출**이 이 게임의 시그니처 샷. 트레일러 첫 장면.
- 유머는 애니메이션과 로그로: 더미가 헬멧이 눈을 가려 허둥대기, 지게차 탈취 시 연구진이 당황하기.

## 8. UI/UX와 모바일 고려
- 좌상단 HP·인스턴스, 우상단 **방 진행 바(사각형 체인)**. 스테이지 구조를 UI가 그대로 말해 준다.
- 관찰 로그는 우상단 아래 3줄 토스트. 전투 중 읽기 부담을 줄이기 위해 방 전환·정비방에서 주로 출력.
- 세션 설계: 방 30~45초, 스테이지 5~7분. 스테이지 중간 종료 시 정비방 체크포인트 저장.
- 성능: Synty 로우폴리 + GPU 인스턴싱, 투사체·적 오브젝트 풀링, 중급 기기 60fps 목표.
- 접근성: 자동 조준 기본 ON, 버튼 크기·위치 커스텀, 색약 모드(적 색 변경).

## 11. 제작 범위 제안 — 버티컬 슬라이스
"재미가 있는지" 검증을 위한 최소 구성:
- 스테이지 1의 5방: 전투 ×2 → 구출 → 전투(장갑차 탈취) → 보스
- 적 4종: 더미 라이플, 러셔, 쉴더, 센트리
- 무기: 권총 + H 헤비 + S 스캐터, 수류탄
- 글리치 대시, 자동 근접, 오버라이드(장갑차 1종)
- 보스 1: 불도저
- 컴파일 전환 연출, 관찰 로그 UI, 방 진행 바
- 가로 모바일 가상 조이스틱 + 자동 조준

데이터 구조는 처음부터 **방 프리팹 + 스폰 테이블(ScriptableObject) + 스테이지 = 방 ID 리스트**로 잡아,
이후 콘텐츠 추가와 무한 모드 전환이 데이터 작업만으로 가능하게 한다.
